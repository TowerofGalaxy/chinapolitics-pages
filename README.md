## 一、作品概述与文献基础

《浪潮与行程》是一部高拟真度、高决策密度的当代中国政治题材互动叙事游戏。全剧以一位具有复旦数学系学术背景、历经基层插队淬炼、在上世纪八十年代干部“年轻化、知识化”浪潮中步入体制的技术官僚（李源潮）为核心视角，全景式推演了从 **1981 年恢复高考后的书斋抉择** 到 **2018 年卸任退隐海淀旧院** 整整三十七年的仕途起伏与时代变迁。

本作品取材于《中国共产党组织史资料》、新华社历届领导人公开发布履历、中共江苏省委与常州市公开文献，以及当代政治学界公开发表的实证研究成果。  
作品不预设立场，不给历史人物进行排名或优劣定级，旨在通过制度机理还原与多难抉择，展现转型期治理的复杂约束条件。

## 二、核心游戏设计原则

1. **绝对去“AI味”与公文白描手法（Anti-AI Realism）**：
   * 彻底清除大模型修辞惯性与刻板标签，严禁旁白替玩家总结意义、解释潜台词或预告选项后果；
   * 人物对话克制短促，讲业务与行政程序，禁止私下排比政论或喊口号；
   * 每个场景结尾均停留在具体的动作、声音或文件细节上；
   * 时代暗号与《滕王阁序》引用严格控制在全剧各 3 处以内，仅用于卷首过场、私人笔记本批注与低数值危机切片，绝不白话翻译解释。
2. **强交互与博弈铁律（Strict Trade-offs, No Win-Win）**：
   * 彻底消灭任何“零代价完美解/双赢选项”；
   * 全剧每个核心选项均严格包含三项刚性结构：`[直接收益]`、`[立刻代价]`、`[后续反噬(Flag)]`；
   * 重要历史事件均拆解为“前期信息搜集(AP) + 多轮交锋/案头批文 + 延迟回收(Flag)”。
3. **双阶状态机与 `variables.json` 唯一字典**：
   * 阶段一（卷一至卷三，1981—2000）：`组织信任度 (cadre_trust)`、`改革锐度值 (reform_acumen)`；
   * 阶段二（卷四至卷六，2000—2018+）：`中央信任度 (central_trust)`、`省内向心力 / 系统协同度 (local_cohesion)`、`财政稳态值 (fiscal_stability)`、`改革开拓度 (reform_drive)`；
   * 严格遵守 [variables.json](variables.json) 定义的变量范围 `[0, 100]` 与 94 项全闭环离散标记（Tag/Flag），并通过 [verify_paths.py](verify_paths.py) 穷举验证全六卷路径闭环、零未定义标记、零禁词与零幽灵变量。

## 四、本地运行网页游戏

需要 Node.js 24 和 pnpm。在仓库目录执行：

```sh
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址。进度保存在当前浏览器中。网页的场景和规则配置位于 `content/`，修改剧本后需要同步对应内容。校验会提示与接入快照不同的分卷。

```sh
pnpm test
pnpm test:paths
pnpm build
pnpm exec vite preview
```

开发结构和分卷验收见 [SPEC.md](SPEC.md)。
